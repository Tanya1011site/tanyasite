# 籌碼觀察

台指選擇權看盤介面的互動原型，採用原生 HTML / CSS / JavaScript，無套件依賴。所有資料均為模擬資料，未串接交易所、券商或下單功能。

## 開發

在 `/workspace/tanyasite` 執行：

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

功能：模擬一分鐘 K 線、可切換的 MA 5 / 10 / 20 / 60 / 144 收盤價均線、合約切換、價平範圍篩選、集中門檻、履約價明細、暫停 / 手動更新、主力集中排行、模擬力道走勢、最近異動。手機版會將面板排成單欄。

## 下一步

確認資料供應商、授權、更新頻率與力道計算定義，再串接正式行情。公開部署至靜態網站服務取得 HTTPS 網址後，可產生 QR Code 供手機掃描。雲端環境的本機服務並非公開部署。

費波納契以最近 50 根 K 線的最高 / 最低價及其先後順序建立回撤基準。多空條件使用收盤價與 MA5/10/20 排列。波浪 P1–P6 僅為左右各兩根 K 線確認的轉折候選，不代表已確認的艾略特波浪；最近兩根尚未確認，滾動區間會改變基準。

手機版預設履約價，可切換 K 線與主力籌碼；頂部價格固定顯示。合約篩選與指標設定可展開，履約價表沒有內部捲動。桌面維持完整看盤面板。

模擬多空大單通知：口數門檻預設 50，可設定方向、選擇音效並測試通知。BC/SP 示意偏多、SC/BP 示意偏空；依模擬異動資料觸發，不確認新倉或真实大單。最近 20 筆通知僅保留於當次頁面，設定保留於瀏覽器；不提供鎖屏推播。

## 兆豐本機行情連動

完整下載並解壓專案，保留 `windows-connector` 在專案目錄內。在 Windows 執行其「啟動.cmd」，提供本機官方 SDK 後登入、訂閱並按「開啟看盤」。本機工具只提供明列的網頁與快照路徑，不提供 DLL、設定或登入資料下載。

真實模式不建立模擬價格、歷史、籌碼與通知。支援即時接收價格、買賣報價、接收時間一分鐘 K 線、MA5/10/20/60/144、費波納契與轉折候選。資料不足不判定均線多空；未平倉與主力資料顯示未接入。選擇權報價鏈限所選到期組別、初始價平附近 9 個履約價；近月連續尚未實作。

大口數成交通知以 SDK 每筆回呼數量為門檻，不保證等同單筆委託或新倉。僅期貨且買賣報價不超過 3 秒、價差有效時推估主動方；其餘標示方向未明。每秒讀取最近 200 筆並依序號去重，切換工作階段或首次進入不重播歷史；離線、頁面節流與高成交速率可能造成通知缺口。不提供背景鎖屏推播。

目前只完成程式與合成快照的瀏覽器驗證，Windows DLL、登入與實際行情仍須在使用者電腦確認。公開 GitHub Pages 預設模擬模式；手機真實同步使用下面的受配對保護通道，不能把券商憑證放到公開前端。

## 手機外網同步

Windows 工具登入並訂閱成功後，按「4. 手機外網同步」，從本機配對頁掃 QR Code。首次以 winget 安裝官方 `Cloudflare.cloudflared`，保留套件校驗；需 Microsoft App Installer / winget。使用 Cloudflare Quick Tunnel 臨時 HTTPS 網址，不需要另外開放入站路由器或防火牆連接埠。

外部通道只轉送到獨立的受保護 loopback listener；電腦原有的本機管理入口不對外轉送。256-bit 隨機配對 token 存在記憶體，最長 8 小時有效、重新啟動即更換。配對後以 Secure / HttpOnly / SameSite cookie 保護所有行情、網頁與 JS 路徑，禁止存取 SDK、設定檔與任意檔案路徑。配對入口將網址中的 token 交換為 cookie 後導向不含 token 的網址，回應採 no-store / no-referrer。

QR Code 使用保留原版授權資訊的 MIT `qrcode-generator@2.0.4`，在本機生成；不將配對連結提交到外部 QR Code 服務。圖書館來源：npm registry，完整性經官方套件 metadata SHA512 驗證。

電腦與工具需要持續開啟，關閉工具會停止它啟動的 tunnel。臨時網址有服務和網路可用性限制，不提供手機鎖屏推播。Cloudflare 中繼行情流量，券商登入帳密不包含於此 HTTP 服務。原 GitHub Pages 網址繼續提供模擬版本，真實行情改從私人配對連結進入。

驗證：`dotnet run --project tests/mobile-server/MobileServerTests.csproj`（在專案根目錄，以 .NET 8 執行）。涵蓋未配對拒絕、cookie、到期、重啟 token、更換主機、檔案白名單與並行请求。完整 Windows C# 程式已用 .NET Framework 4.7.2 參考程序集及官方 SDK DLL 編譯檢查；實際 Windows 安裝通道、券商登入與外網手機連線仍需在使用者電腦確認。

## 選擇權即時報價鏈

Windows 登入載入商品後，在「選擇權組別」選擇到期日，再訂閱台指期 TXF 或小台 MXF 單月合約。收到第一筆期貨報價／成交後，自動選出該組別、距現價最近的 9 個完整 CALL / PUT 配對（18 檔），加上期貨最多 19 檔，遵循官方範例的 20 檔訂閱限制。API 不接受訂閱時會在表格標示；送出訂閱與實際收到報價保持不同狀態。

使用官方 ContractInfo 的 MaturityDate、StrikePx、CallPut，單式代碼作後備辨識。預設選尚未到期的最近 TXO 組別，可手動選其他組別。顯示最新買／賣報價、成交價／單筆口數、本次接收成交累計；不將成交量当作未平倉。不完整的 CALL/PUT 配對不會生成假商品。範圍在訂閱時固定，不自動重訂閱換組；換組需重啟工具。

選擇權成交亦可觸發口數通知，但方向標為未明，不推造多空或新倉身份。主力、大戶散戶與未平倉仍需額外可驗證的資料來源。手機從已配對的 HTTPS 入口讀取同一份選擇權快照。
