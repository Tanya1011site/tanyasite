# 籌碼觀測站

台指期貨與選擇權看盤介面。GitHub Pages 為明確標示的模擬展示；真實行情由 Windows 10 的兆豐 SpeedyAPI 連接工具提供，不含下單功能。

## Windows 操作

1. 關閉舊的 Connector，下載並「解壓縮全部」專案 ZIP；保留整個目錄結構。
2. 雙擊 `windows-connector/啟動.cmd`。工具優先重用桌面／下載資料夾內舊版本的完整官方 x86 SDK；找不到才要求選擇已解壓的 SpeedyAPI_CS 或舊 windows-connector。公開專案不附券商 DLL、設定或登入資料。
3. 登入兆豐提供的行情主機、Port、行情帳密，按「2. 訂閱商品」。預設選可交易的近月大台，結算後每分鐘檢查換月；可改為日曆當月，已到期就提示，不默默選遠月。到期日優先採 SDK，缺少日期才用一般第三週三。
4. 工具訂閱同月份 TXF 大台、MXF 小台、TMF 微台，與當月 TXO 月選；排除週選和跨月組合。商品未提供或訂閱遭拒會標示。遵循官方範例的 20 檔上限：三檔期貨加八個履約價的 CALL/PUT，共 19 檔。選擇權區間在第一次收到大台價格時決定；重啟可重新選價平範圍。
5. 按「3. 開啟看盤」。按「5. 回補近一週資料」嘗試下載期交所日報與前七個完成日期的逐筆 ZIP；下載時即時行情繼續接收。失敗、休市、格式不符、大小超限均保留缺口。也可「匯入期交所 CSV／ZIP」。
6. 手機用「4. 手機外網同步」產生的 QR Code 配對，可使用行動網路；電腦與工具必須保持開啟。公開 GitHub Pages 的展示網址仍為模擬模式。

需要 .NET Framework 4.7.2+。啟動腳本用 Windows 隨附的 C# 編譯器編譯原始碼。帳密只放於程序記憶體，不寫入歷史或網頁。請勿提交本機 SDK、設定或憑證到 GitHub。

## 歷史與週統計

資料保存於 `%LOCALAPPDATA%\TanyaSiteMarketHistory`，每 60 秒及正常關閉時寫入。重啟、換下載版本會載入同一目錄，最多還原最近 600 根有成交的一分鐘 K 線；非正常關閉可能遺失最後一次寫入後的資料。為避免兩個新版本同時寫入，目錄採程序鎖；無法取得鎖時顯示保存失敗。

「週資料」頁提供今天及前六個臺北日曆日的成交累計、主動方推估、方向未明口數、日期／商品／日夜盤查詢、盤中成交分鐘折線、保存的大額成交、官方日報未平倉與變動。這是七個日曆日，不是七個交易日。涵蓋日期、來源、最後更新與缺口均明列；只有本機接收時不宣稱全天／整週完整。

- 本機 K 線依接收時間分桶；夜盤 15:00–05:00 以開盤日標示，凌晨屬前一天。官方逐筆使用來源成交日期／時間；日報使用交易所交易日，二者不可任意混合日期。
- 日報未平倉取各合約的一般時段公布值，保留最新公布日期。日變動對前一筆日報；週變動對週起點以前最後公布值。缺基準留空；零值保留為零。成交量加總與未平倉存量分開，不能用成交量推造未平倉。
- 歷史逐筆缺前序委託報價，主動方維持未明。BC/SC/BP/SP 和淨口數只包含能判定的本機成交，不能辨識主力、散戶、開倉或平倉身份。
- CSV 僅接收可辨識的期交所欄位、月契約及台指產品；週選與跨月組合不混入。明確為 `成交數量(B+S)` 的逐筆欄位除以二換成單邊口數；奇數拒絕匯入。匯入檔案必須完整涵蓋要替換的成交分鐘，重複匯入替換相同商品／分鐘而不疊加，本機主動方推估會被來源未知方向取代。
- CSV 可讀 UTF-8／Big5；ZIP 只串流讀取 CSV、不解壓任意路徑。限制日報 50 MB、下載 ZIP 128 MB、逐筆 CSV 512 MB。檔案超限會回報，不能視為完整資料。

官方下載入口採 `www.taifex.com.tw` 的 futDataDown／optDataDown、Daily／OptionsDaily 逐筆檔路徑，使用系統 TLS 憑證驗證。這輪雲端取得官方資料遭 HTTP 403，尚未以實際官方下載檔完成端到端驗證；目前已驗證可辨識格式的合成 CSV、持久化與計算。來源不符時報錯，保留手動匯入入口。**功能完成不等於已取得一整週真實資料。**

## 日夜盤分析與通知

1 分 K 僅繪製成交與 MA5／10／20／60／144。沒有成交分鐘不補假線，均線缺期數就留空。

費波納契是獨立面板，以選定日盤／夜盤最高、最低及震幅計算 0、23.6、38.2、50、61.8、78.6、100%，可切換高點向下回撤／低點向上反彈。特別標示最近末價的價位、盤段端點和多空失效條件。多空提示依盤段末價與區間中點，與 1 分 K 無關。

波浪候選來自逐筆價格反轉，動態門檻為 max(10 點, 已觀察盤段震幅 × 10%)；只記已確認反轉，不把尚未反轉的末段當完整波。標示 P 候選，未驗證完整艾略特規則。逐筆順序不符時停用波浪；官方日報 OHLC 只能建立費波區間，無法還原波浪。

真實通知預設：大小微台每筆成交 ≥300 口；選擇權 ≥50 口。選擇權成交權利金 = 成交價 × 官方合約乘數 × 口數（TXO 後備乘數 50），**嚴格大於** NT$500,000 特別標註；剛好 500,000 不標註。成交未達 50 口時，即使金額大也不觸發預設通知。

通知門檻與方向可另調；週期貨力道分類固定 300 口。每個商品使用自己的前序買賣報價，只有有效、未交叉、不超過三秒且早於成交的報價才推估主動方。不能保證回呼等於單一委託或新倉。快照包含最近 500 筆成交及當次連線保存的大額成交，依序號去重；初次開頁不重播舊通知，超過十秒的舊成交不彈提示。歷史紀錄可在週資料查閱。瀏覽器節流、離線或高流量仍可能造成通知缺口；不提供鎖屏推播。

## 手機同步

首次透過 winget 安裝官方 `Cloudflare.cloudflared`，保留套件校驗。需 Microsoft 官方 App Installer／winget。Cloudflare Quick Tunnel 提供臨時 HTTPS 配對網址，不需開放路由器入站埠。

外部通道只轉送受配對保護的獨立 loopback listener，所有 HTML、JS、快照與歷史 API 都驗證 cookie。256-bit 隨機 token、最長八小時效期、重啟更換；配對入口將 token 交換為 Secure／HttpOnly／SameSite cookie，採 no-store／no-referrer。管理入口、SDK、設定檔、任意檔案與路徑穿越都不對外提供。Cloudflare 會中繼行情流量；登入帳密不包含於 HTTP 服務。

QR Code 用本機 `qrcode-generator@2.0.4`（MIT，npm 完整性已校驗）生成，未送外部 QR 服務。手機四個分頁：履約價、K 線、成交力道、週資料；履約表不設內部捲動，歷史大表可水平檢視。

## 驗證與開發

```sh
python3 -m http.server 8000 --bind 0.0.0.0
dotnet run --project tests/mobile-server/MobileServerTests.csproj
node tests/browser/market-history.cjs
```

瀏覽器測試需 Playwright 與 Chromium（可用 `CHROMIUM_PATH` 指定）。測試涵蓋保存與重啟、跨午夜與週起點、匯入替換／去重、OI 零值與缺基準、日夜盤逐筆波浪、月份與訂閱上限、通知 299/300、49/50、50 萬邊界、手機各分頁及歷史端點配對。完整 Windows 程式以 .NET Framework 4.7.2 參考程序集和官方 managed SDK 做編譯檢查；Linux 無法執行 Windows 原生 DLL。實際券商訂閱、歷史下載及手機網路須由使用者電腦確認。
