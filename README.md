# 籌碼觀察

台指選擇權看盤介面的互動原型，採用原生 HTML / CSS / JavaScript，無套件依賴。所有資料均為模擬資料，未串接交易所、券商或下單功能。

## 開發

在 `/workspace/tanyasite` 執行：

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

功能：模擬一分鐘 K 線、可切換的 MA 5 / 10 / 20 / 60 / 144 收盤價均線、合約切換、價平範圍篩選、集中門檻、履約價明細、暫停 / 手動更新、主力集中排行、模擬力道走勢、最近異動。手機版會將面板排成單欄。

## 下一步

確認資料供應商、授權、更新頻率與力道計算定義，再串接正式行情。公開部署至靜態網站服務取得 HTTPS 網址後，可產生 QR Code 供手機掃描。雲端環境的本機服務並非公開部署。

費波納契以最近 50 根 K 線的最高 / 最低價及其先後順序建立回撤基準。多空條件使用收盤價與 MA5/10/20 排列。波浪 P1–P6 僅為左右各兩根 K 線確認的轉折候選，不代表已確認的艾略特波浪；最近兩根尚未確認，滾動區間會改變基準。

手機版預設履約價，可切換 K 線與主力籌碼；頂部價格固定顯示。合約篩選與指標設定可展開，履約價表沒有內部捲動。桌面維持完整看盤面板。

模擬多空大單通知：口數門檻預設 50，可設定方向、選擇音效並測試通知。BC/SP 示意偏多、SC/BP 示意偏空；依模擬異動資料觸發，不確認新倉或真实大單。最近 20 筆通知僅保留於當次頁面，設定保留於瀏覽器；不提供鎖屏推播。

## 兆豐本機行情連動

完整下載並解壓專案，保留 `windows-connector` 在專案目錄內。在 Windows 執行其「啟動.cmd」，提供本機官方 SDK 後登入、訂閱並按「開啟看盤」。本機工具只提供明列的網頁與快照路徑，不提供 DLL、設定或登入資料下載。

真實模式不建立模擬價格、歷史、籌碼與通知。支援即時接收價格、買賣報價、接收時間一分鐘 K 線、MA5/10/20/60/144、費波納契與轉折候選。資料不足不判定均線多空；未平倉與主力資料顯示未接入。完整選擇權鏈與近月連續尚未實作。

大口數成交通知以 SDK 每筆回呼數量為門檻，不保證等同單筆委託或新倉。僅期貨且買賣報價不超過 3 秒、價差有效時推估主動方；其餘標示方向未明。每秒讀取最近 200 筆並依序號去重，切換工作階段或首次進入不重播歷史；離線、頁面節流與高成交速率可能造成通知缺口。不提供背景鎖屏推播。

目前只完成程式與合成快照的瀏覽器驗證，Windows DLL、登入與實際行情仍須在使用者電腦確認。公開 GitHub Pages 預設模擬模式；手機真實同步仍需受保護的後端，不能把券商憑證放到公開前端。
