兆豐行情連接工具 · Windows 10 · 第一階段

1. GitHub ZIP 下載後，按右鍵「解壓縮全部」。另外先解壓兆豐提供的 SpeedyAPI_CS.7z。不能在壓縮檔視窗內直接執行。
2. 開啟 windows-connector 資料夾，雙擊「啟動.cmd」。首次會要求選擇已解壓的 SpeedyAPI_CS 資料夾，工具會複製必要 DLL、Temp 與設定檔到本機。首次執行會利用 Windows 的 .NET Framework 編譯工具建立 Connector.exe。
3. 在視窗填入兆豐提供的「行情」主機、連接埠、帳號、密碼，按「1. 登入行情」。不是交易主機，也不使用下單憑證。
4. 商品清單出現後，選目前交易的期貨或選擇權合約，按「2. 訂閱商品」。不要使用官方範例的舊合約代碼。
5. 按「3. 開啟看盤」。有成交後才會出現價格與 K 線。切換商品或斷線後需關閉工具再啟動。

帳號密碼僅存在本次程式記憶體，不寫入檔案，不送到 GitHub。本工具僅訂閱一檔行情，不含下單功能。
本機網頁僅綁定 127.0.0.1:8765，不需開放防火牆或將電腦暴露到網際網路。
K 線依接收時間分桶；沒有歷史回補，不補模擬資料。累積 144 根成交分鐘 K 線後才會顯示 MA144。
此階段未將資料送到已發布網站，也未提供手機連線、未平倉或主力籌碼。

公開下載僅包含自行撰寫的程式碼，不含兆豐 DLL 或設定檔；執行時使用你本機的官方套件。
已檢查來源 API 範例與網頁呈現；雲端是 Linux，尚不能驗證 Windows 編譯、原生 DLL 載入或你的實際行情登入。
若啟動時出現錯誤，請截圖傳回（遮住帳號、主機與其他登入資料）。
需要 .NET Framework 4.7.2 或更新版本；若電腦未安裝，請透過 Microsoft 官方來源安裝，勿下載不明 DLL。
電腦需保持開機、程式運作，才會持續接收行情。
