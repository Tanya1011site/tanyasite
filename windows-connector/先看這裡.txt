兆豐行情連接工具 · Windows 10

1. 關閉舊工具。下載完整專案 ZIP，按右鍵「解壓縮全部」，不要在壓縮檔內執行。
2. 打開 windows-connector，雙擊「啟動.cmd」。會先找舊版本的官方 SDK；若要求選資料夾，選已解壓的 SpeedyAPI_CS 或舊的完整 windows-connector。
3. 填兆豐提供的行情 IP、Port、帳號、密碼，按「1. 登入行情」。登入資料只在記憶體，不會保存到歷史。
4. 預設自動選近月大台與同月 TXO 月選，結算後檢查換月；「日曆當月」在已到期時會提示。按「2. 訂閱商品」同時訂閱大台、小台、微台與八個價平附近 CALL／PUT 配對。遵循 SDK 20 檔上限，並非完整月選即時串流。
5. 按「3. 開啟看盤」看電腦行情。大小微台 300 口、選擇權 50 口為通知預設門檻；選擇權權利金超過 50 萬特別標註，剛好 50 萬不標。
6. 按「5. 回補近一週資料」嘗試下載期交所日報與已完成日期逐筆 ZIP。也可匯入官方 CSV／ZIP。這輪雲端下載來源遇 403，Windows 實際下載尚待確認；失敗會提示，不假造資料。沒有日報就沒有未平倉。
7. 手機／電腦「週資料」可選日期、商品、日／夜盤，查歷史、週口數、官方未平倉及週變動。週口徑為今天及前六個臺北日曆日，只有收到或回補的部分；查來源日期確認缺口。
8. 手機在外面使用「4. 手機外網同步」的 QR Code 配對，電腦與程式需一直開啟。原 GitHub Pages 是模擬展示，不會自動變成真實行情。

歷史每 60 秒及正常關閉保存到：
%LOCALAPPDATA%\TanyaSiteMarketHistory
新版會沿用此目錄，重啟不清空；非正常關閉可能失去最後一次保存後的資料。不能同時開兩個新版本寫入同一歷史目錄。

費波改用日夜盤高低與震幅。波浪使用逐筆反轉候選 P，沒有逐筆資料就不猜波數；均線仍使用 1 分 K。
未平倉為盤後公布，不能由成交量反推。買賣力道僅依有效的前序報價推估；未知方向留空，不能確認主力、散戶或新倉身份。

需要 .NET Framework 4.7.2+，公開下載不含券商 DLL／設定檔。若啟動報錯，截圖前遮住行情主機、帳號及其他登入資料。
手機首次同步會用 winget 安裝官方 Cloudflare.cloudflared；缺 winget 請從 Microsoft Store 更新官方「應用程式安裝程式」。
不要分享配對 QR Code／連結。配對最長 8 小時，重啟換連結。不需要開路由器埠。Cloudflare 中繼行情流量，券商帳密不包含在此 HTTP 服務。
通知需頁面保持開啟，手機鎖屏不提供推播；離線或節流可能漏通知，保存的大額成交可到週資料查閱。
